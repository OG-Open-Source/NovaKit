Introduction

Welcome to the official documentation.

This documentation is designed to help you get up and running with the platform as quickly as possible. We cover everything from basic installation to advanced configuration.

Prerequisites

Before you begin, ensure you have met the following requirements:

  • Node.js v14 or higher
  • NPM or Yarn package manager
  • Basic understanding of HTML/CSS

Quick Install

npm install @knowledge-hub/core
npm run start
Tip: Check out the Wiki for community-contributed guides.
