How to Use

The novakit-superellipse.js script allows you to apply a responsive superellipse shape to any HTML element declaratively.

1. Include the script

Add the script to your HTML file. Use the defer attribute so it runs after the document is parsed.

<script src="https://novakit.ogtt.tk/tools/novakit-superellipse.js" defer></script>

2. Add the data attribute

Add data-superellipse to any element to apply the shape. The script will automatically find and initialize it.

3. Control the shape (optional)

Use data-n to control the roundness. A lower value is more rounded; a higher value is sharper. The default is 4.
